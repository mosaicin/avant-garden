# Avant-Garden

Открытый многостраничный сайт о встрече природы, художественного процесса и геометрического мышления. Визуальный язык соединяет резкие поля русского авангарда и футуризма с функциональной навигацией Баухауса.

## Структура

- `index.html` — главная страница: поле, метод и три смысловых входа.
- `nature.html` — природа как соавтор: свет, сопротивление, интервалы.
- `works.html` — демонстрационный архив художественных работ с материалом, временем и описанием процесса.
- `carousel.html` — экспериментальная карусель-наблюдение с двумя уникальными фотографиями, кнопками, клавиатурным управлением и свайпом.
- `assets/photo-01.webp`, `assets/photo-02.webp` — два уникальных публичных кадра из подготовленного фото-дневника.
- `style.css` — общий адаптивный стиль.
- `app.js` — интерактивность карусели.

## Важное о визуальных материалах

Геометрические композиции созданы специально для этого проекта средствами CSS и не являются копиями конкретных произведений. В открытый репозиторий добавлены только два уникальных кадра из подготовленного фото-дневника; точные дубликаты удалены по SHA-256. Точные GPS и индивидуальные даты не публикуются, поскольку не подтверждены. Исходные личные файлы не изменяются.

## Локальный просмотр

Проект не требует сборки. Откройте `index.html` в браузере или запустите любой статический сервер из корня репозитория, например:

```bash
python3 -m http.server 8080
```
