# Avant-Garden

Открытый многостраничный сайт о встрече природы, художественного процесса и геометрического мышления. Визуальный язык соединяет резкие поля русского авангарда и футуризма с функциональной навигацией Баухауса.

## Структура

- `index.html` — главная страница: поле, метод и входы в структурированный архив.
- `nature.html` — отдельная страница природы и наблюдений.
- `workshops.html` — отдельная страница мастерских и рабочего процесса.
- `drawings.html` — отдельная страница рисунков и линий.
- `works.html` — отдельная страница художественных работ.
- `carousel.html` — экспериментальная карусель-наблюдение с управлением кнопками, клавиатурой и свайпом.
- `assets/archive/` — 2107 уникальных кадров, распределённых по четырём категориям.
- `archive-filters.js` — фильтры по серии и году на страницах природы, мастерских, рисунков и работ; выбор сохраняется в URL.
- `assets/public/` — предыдущий безопасный набор, сохранённый для совместимости.
- `assets/photo-01.webp`, `assets/photo-02.webp` — исходные preview-кадры, сохранённые для совместимости.
- `style.css` — общий адаптивный стиль.
- `app.js` — интерактивность карусели.

## Важное о визуальных материалах

Геометрические композиции созданы специально для этого проекта средствами CSS и не являются копиями конкретных произведений. Новый архив разделён на четыре страницы: природа, мастерские, рисунки и художественные работы. После дополнительной части Google Takeout обработано 897 новых уникальных кадров; 737 безопасных изображений добавлено в GitHub, всего опубликовано 2107 файлов. Банковские карты, документы, чеки, QR-коды, карты местности и интерфейсные скриншоты исключены; лица и мастерские разрешены по вашему указанию. Точные повторы удалены по SHA-256. Все новые изображения пересохранены без исходных EXIF/GPS, а геолокации и точные адреса не публикуются. Фильтры годов используют реальные папки Takeout (2007, 2019–2025), а фильтры серий — реальные названия альбомов; для кадров без подтверждённого года показывается «Год не указан».

## Локальный просмотр

Проект не требует сборки. Откройте `index.html` в браузере или запустите любой статический сервер из корня репозитория, например:

```bash
python3 -m http.server 8080
```
