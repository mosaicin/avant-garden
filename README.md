# Avant-Garden

Открытый многостраничный сайт о встрече природы, художественного процесса и геометрического мышления. Визуальный язык соединяет резкие поля русского авангарда и футуризма с функциональной навигацией Баухауса.

## Структура

- `index.html` — главная страница: поле, метод и три смысловых входа.
- `nature.html` — природа как соавтор: свет, сопротивление, интервалы.
- `works.html` — демонстрационный архив художественных работ с материалом, временем и описанием процесса.
- `carousel.html` — экспериментальная карусель-наблюдение со 134 отфильтрованными фотографиями, кнопками, клавиатурным управлением и свайпом.
- `assets/public/` — 134 уникальных публичных кадра без банковских карт, чеков, документов и очевидных личных данных.
- `assets/photo-01.webp`, `assets/photo-02.webp` — исходные два preview-кадра, сохранённые для совместимости.
- `style.css` — общий адаптивный стиль.
- `app.js` — интерактивность карусели.

## Важное о визуальных материалах

Геометрические композиции созданы специально для этого проекта средствами CSS и не являются копиями конкретных произведений. В открытый репозиторий добавлен консервативно отфильтрованный архив из 134 кадров: удалён один точный дубликат, исключены банковские карты, чеки, документы, экраны телефонов, узнаваемые лица и очевидные личные детали. Фотографии пересохранены без исходных EXIF/GPS; точные адреса и индивидуальные даты не публикуются.

## Локальный просмотр

Проект не требует сборки. Откройте `index.html` в браузере или запустите любой статический сервер из корня репозитория, например:

```bash
python3 -m http.server 8080
```
