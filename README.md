# Avant-Garden

Открытый многостраничный сайт о встрече природы, художественного процесса и геометрического мышления. Визуальный язык соединяет резкие поля русского авангарда и футуризма с функциональной навигацией Баухауса.

## Структура

- `index.html` — главная страница: поле, метод и три смысловых входа.
- `nature.html` — природа как соавтор: свет, сопротивление, интервалы.
- `works.html` — демонстрационный архив художественных работ с материалом, временем и описанием процесса.
- `carousel.html` — экспериментальная карусель-наблюдение со 134 отфильтрованными фотографиями, кнопками, клавиатурным управлением и свайпом.
- `nature-archive.html` — отдельная страница природы.
- `workshops-archive.html` — отдельная страница мастерских и рабочего процесса.
- `drawings-archive.html` — отдельная страница всех рисунков.
- `works-archive.html` — отдельная страница художественных работ.
- `assets/archive/` — 297 уникальных кадров, распределённых по четырём категориям.
- `assets/public/` — предыдущий безопасный набор, сохранённый для совместимости.
- `assets/photo-01.webp`, `assets/photo-02.webp` — исходные preview-кадры, сохранённые для совместимости.
- `style.css` — общий адаптивный стиль.
- `app.js` — интерактивность карусели.

## Важное о визуальных материалах

Геометрические композиции созданы специально для этого проекта средствами CSS и не являются копиями конкретных произведений. Новый архив разделён на четыре страницы: природа, мастерские, рисунки и художественные работы. Банковские карты и документы исключены; лица и мастерские разрешены по вашему указанию. Точные повторы удалены по SHA-256. Все опубликованные изображения пересохранены без исходных EXIF/GPS, а геолокации и точные адреса не публикуются.

## Локальный просмотр

Проект не требует сборки. Откройте `index.html` в браузере или запустите любой статический сервер из корня репозитория, например:

```bash
python3 -m http.server 8080
```
